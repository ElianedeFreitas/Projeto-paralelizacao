Alunas: Eliane de Freitas e Rayna Livia
Professor: Rafael Marconi Ramos
Curso: Análise e Desenvolvimento de Sistemas

Introdução

Este relatório tem como objetivo apresentar o desenvolvimento de um contador de palavras utilizando conceitos de Programação Concorrente aplicados ao processamento de bases de dados extraídas da Wikipédia. O projeto busca analisar o desempenho e a eficiência da execução concorrente no tratamento de grandes volumes de informações textuais.

Para a realização da atividade, será utilizada a base de dados denominada “Redes de artigos da Wikipédia”, classificada como um Explorador de Dados, na versão 1.1, com tamanho aproximado de 11,14 MB.
